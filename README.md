Descripción del sitio
Landing Page de 5 secciones para una billetera virtual local ficticia llamada "MC Wallet". El sitio simula una fintech argenta para enviar dinero, pagar con QR, pagar servicios y hacer rendir los ahorros. Diseño inspirado en estilo neón nocturno.

Objetivo del Sitio
Crear una propuesta visual moderna y funcional que demuestre el dominio de HTML semántico, CSS avanzado y diseño responsive, con temática económica actual (billetera virtual) para promocionar la materia.

Estructura del sitio - 5 secciones
1.  Inicio : Presentación, propuesta de valor y tarjeta de saldo
2.  Funciones:  4 funcionalidades (Enviar, QR, Ahorro, Servicios)
3.  Beneficios: Flexbox con ventajas (Seguridad, Sin comisiones, Cashback)
4.  La App en acción: Galería multimedia con imagen, video de YouTube y audio de notificación
5.  Contacto: Formulario de contacto funcional con validación HTML5

Tecnologías utilizadas
- Lenguajes: HTML5 (etiquetas semánticas: header, nav, main, section, article, footer, form), CSS3
- Estilos: Variables CSS (:root), Flexbox, CSS Grid, Media Queries para Responsive
- Tipografías: Google Fonts - Poppins (títulos) e Inter (textos)
- Íconos: Font Awesome 6.5
- Animaciones / Librerías: AOS (Animate On Scroll) - librería CSS para animaciones al hacer scroll
- Recursos Multimedia: Imágenes tomadas de Pinterest, video iframe de YouTube, etiqueta audio HTML5
